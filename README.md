\# Underwriting ML Platform



A production-oriented machine learning platform for credit underwriting and decision optimisation.



\## Objective



The project explores the complete lifecycle of a machine-learning underwriting system, from raw application data to production credit

decisions.



The platform will progressively include:



\- data ingestion and validation

\- exploratory data analysis

\- feature engineering

\- probability-of-default modelling

\- probability calibration

\- model evaluation

\- economic decision optimisation

\- approval threshold optimisation

\- experiment tracking

\- model registry

\- API-based model serving

\- automated testing

\- containerisation

\- CI/CD

\- model and data monitoring

\- drift detection

\- explainability

\- fairness analysis

\- model governance

\- cloud deployment



\## Decision problem



The system will estimate the probability that an applicant defaults:



P(default | applicant information)



The predictive model will then form part of a broader underwriting decision system in which approval decisions depend on both predicted

risk and the economic consequences of lending decisions.



The project therefore distinguishes between:



1\. predictive modelling;

2\. probability estimation and calibration;

3\. decision optimisation;

4\. business value.
